# MainEntry Journal

Daily bilingual (English + Spanish) articles by Maria Myers, MainEntry LLC, on AI, small business, getting found online, online safety, ADHD & focus, and making money with AI.

Built with Jekyll on GitHub Pages. New articles go in `_posts/` as `YYYY-MM-DD-slug.md`.

Front matter used by each post:

```
---
title: "English title"
title_es: "Título en español"
description: "One-sentence summary for Google (150-160 characters)."
categories: [ai-visibility]   # one of: ai-visibility, online-safety, ai-tools, make-money-with-ai, adhd-focus, ai-news
has_spanish: true
---
```

Put `<h2 id="espanol">🇪🇸 Español</h2>` before the Spanish version so the "Leer en español" link jumps there.
